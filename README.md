# StockControl — Projeto Integrador

Projeto acadêmico desenvolvido para o curso de Análise e Desenvolvimento de Sistemas da UCEFF — 2026/2.

## Sobre o projeto

O StockControl é um sistema web de gerenciamento de estoque destinado a pequenas empresas, desenvolvido utilizando HTML, CSS, JavaScript, PHP e MariaDB.

Seu objetivo é facilitar o gerenciamento de produtos, fornecedores, categorias e movimentações de estoque.
 
## Funcionalidades

- Autenticação de usuários.
- Cadastro, consulta, edição, inativação e reativação de produtos.
- Gerenciamento de fornecedores.
- Cadastro e consulta de categorias.
- Registro de entradas e saídas de estoque.
- Atualização automática do saldo.
- Validação de estoque insuficiente.
- Identificação de produtos com estoque baixo.
- Histórico de movimentações.
