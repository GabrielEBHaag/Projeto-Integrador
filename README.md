# Projeto-Integrador
StockControl — Projeto Integrador

Projeto acadêmico desenvolvido para o curso de Análise e Desenvolvimento de Sistemas da UCEFF.

O StockControl é um sistema de gerenciamento de estoque desenvolvido utilizando PHP, JavaScript e MariaDB.

Unidade I: planejamento inicial do projeto, disponível em PDF neste repositório.

Unidade II: desenvolvimento inicial do banco de dados, protótipos das interfaces e implementação das funcionalidades básicas.

Os arquivos do sistema e a documentação técnica estão disponíveis na pasta StockControl_Unidade_II_Revisado/StockControl.
